# Notch Companion — Windows Desktop Application

> An ambient desktop companion for focus, ergonomics, and daily wellbeing.
> Lives quietly at the top of your screen as a translucent dark island. 100% offline, zero telemetry, local-first.

See the root [`README.md`](../../README.md) for full project documentation, architectural overview, and feature tour.
See [`DEMO_SCRIPT.md`](../../DEMO_SCRIPT.md) for a 3-minute presentation script with step-by-step cue cards.

### Quick Start
```powershell
# Development
npm install
npm run dev

# Build Windows Installer
npm run build
npx tauri build
```
